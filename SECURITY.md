# Política de segurança

## Versões suportadas

Este projeto está em desenvolvimento e ainda não tem versões publicadas. Só a branch `main` recebe correções de segurança.

## O que podes esperar

Este é um projeto pessoal, mantido por uma só pessoa. Vou tentar responder em poucos dias e manter-te a par do estado da correção. Não posso garantir prazos exatos.

## Âmbito

Esta política aplica-se ao código deste repositório. Falhas em serviços de terceiros usados pelo projeto (por exemplo o GitHub) devem ser reportadas aos respetivos responsáveis.
